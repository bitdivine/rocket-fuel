# Specification

## Summary
**Goal:** Change the app's global background colour from chocolate-brown to a sickly green tone.

**Planned changes:**
- Update CSS custom properties and/or Tailwind config to replace the chocolate-brown background with a muted, sickly yellow-green (e.g. #8DB600) for both light and dark modes.

**User-visible outcome:** The entire app background appears in a sickly green colour across both light and dark modes, while all other design colours remain unchanged.
